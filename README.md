# Sistema de Monitoramento Energético Espacial

## Objetivo

Desenvolver uma solução computacional para monitorar sistemas de energia de uma missão espacial.

## Funcionalidades

* Monitoramento de temperatura
* Monitoramento de energia
* Monitoramento de comunicação
* Geração automática de alertas
* Recomendações para situações críticas

## Tecnologias Utilizadas

Python

## Como Executar

1. Instalar Python.
2. Executar:

python main.py

3. Inserir os dados solicitados pelo sistema.

## Exemplo

Temperatura: 90
Energia: 15
Comunicação: 0

Resultado:

* Superaquecimento detectado.
* Nível crítico de energia.
* Falha de comunicação.
* Recomendações automáticas.
